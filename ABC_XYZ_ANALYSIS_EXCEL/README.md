
# Дашборд аналитики продаж (Excel) 

Готовый аналитический дашборд в Excel с ABC‑XYZ‑сегментацией и динамикой KPI. Проект демонстрирует навыки работы с данными, построения аналитических отчётов, формулирования рекомендаций и подготовки артефактов для команды.

## Цель проекта

Создать воспроизводимый инструмент для мониторинга выручки, среднего чека, ассортимента и динамики продаж по сегментам. На основе дашборда — выявить драйверы выручки, проблемные зоны и сформировать рекомендации по оптимизации товарной матрицы. Решение реализовано в Excel как MVP‑инструмент с перспективой переноса в BI‑систему.

## Что реализовано

- **Сводные метрики:** общая выручка, средний чек, количество уникальных товаров.  
- **ABC‑анализ:** распределение выручки и количества товаров по группам AA, BB, CC.  
- **ABC_XYZ‑сегментация:** выручка и количество проданных единиц по сегментам (AAX, AAY, AAZ, BBX и т. д.).  
- **Динамика по месяцам:** тренды выручки и количества проданных единиц по группам ABC.  
- **Интерактивность:** срезы для фильтрации по периоду, ABC‑группам и ABC_XYZ‑сегментам.  
- **Воспроизводимость:** логика сегментирования вынесена в отдельные справочники; расчёты реализованы через сводные таблицы и формулы Excel.

## Данные

- **Период:** январь — август 2025 года.  
- **Источники:** выгрузки из ERP‑системы в формате XLSX.  
- **Метрики:** выручка (руб.), средний чек (руб.), количество уникальных товаров, количество проданных единиц.  

## Структура репозитория

- `Дашборд ABC-XYZ-анализ.xlsx` — основной файл с дашбордом (сводные таблицы, графики, срезы).   
- `README.md` — текущая документация.  
- `Аналитическая записка.pdf` — аналитическая записка с выводами и рекомендациями.  

## Навыки, продемонстрированные в проекте

- **Анализ данных:** ABC‑ и XYZ‑анализ, сегментация, выявление драйверов и проблемных зон, проверка гипотез.  
- **Визуализация и UX дашбордов:** построение диаграмм (круговые, столбчатые, линейные), настройка срезов, работа со сводными таблицами, обеспечение читаемости и удобства использования.  
- **Документирование:** подготовка аналитической записки и README для команды, описание методологии и источников данных.  
- **Воспроизводимость и поддержка:** логика расчётов вынесена в справочники, формулы структурированы для лёгкого сопровождения.  
- **Планирование развития:** описание плана переноса в BI‑систему и расширения функциональности.  

## Как использовать

1. Откройте `Дашборд ABC-XYZ-анализ.xlsx`.  
2. Используйте срезы слева (Период, ABC, ABC_XYZ) для фильтрации данных.  
3. Анализируйте сводные метрики и графики для принятия управленческих решений.  
4. При необходимости обновите данные в листе с исходниками и обновите сводные таблицы.
